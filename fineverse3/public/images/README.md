# FINEVERSE image slots

Every image on the site comes from **`lib/images.ts`**. Right now they are generated SVG
artwork, so the site works with zero photos. To use a real photo:

1. Put the file in the folder listed below (keep the filename convention).
2. Open `lib/images.ts` and add **one line** to `FILE_OVERRIDES`:

```ts
const FILE_OVERRIDES = {
  "product:sisters-revenge-oversized-tee:cosmic-pitch-black:front": {
    src: "/images/products/sisters-revenge-oversized-tee/cosmic-pitch-black-front.jpg",
  },
};
```

No component changes are needed. Alt text is generated from your product and collection data.

## Rules for every image

- Keep the **aspect ratio** in the table. A different ratio would crop. If your export has a
  different pixel size but the same ratio, add `width` and `height` to the override.
- Formats: `.jpg`, `.webp`, `.avif` or `.png`. Next.js serves AVIF/WebP automatically.
- Export at roughly **2x** the "min" size, then compress (aim for under 300 KB per product shot).
- Model/flat-lay shots on a clean or dark background work best with the dark theme.
- Only the home hero image is loaded with high priority. Do not add more.

## Slots

| Slot | Override key | File (under `/public/images`) | Ratio | Min size | Recommended |
|------|--------------|-------------------------------|-------|----------|-------------|
| Product shot | `product:{slug}:{colorId}:{view}` | `products/{slug}/{colorId}-{view}.jpg` | 4:5 | 800 x 1000 | 1600 x 2000 |
| Home hero | `hero` | `heroes/hero.jpg` | 4:5 | 1200 x 1500 | 2400 x 3000 |
| Category tile | `category:{categoryId}` | `categories/{categoryId}.jpg` | 4:5 | 800 x 1000 | 1600 x 2000 |
| Collection banner | `collection:{slug}` | `collections/{slug}.jpg` | 16:9 | 1600 x 900 | 2400 x 1350 |
| Drop banner | `drop:{dropId}` | `drops/{dropId}.jpg` | 2:1 | 1600 x 800 | 2400 x 1200 |
| Video thumbnail | `thumbnail:{variant}` | `videos/{variant}.jpg` | 16:9 | 1280 x 720 | 1920 x 1080 |
| Avatar | `avatar:{variant}` | `avatars/{variant}.jpg` | 1:1 | 160 x 160 | 320 x 320 (set `width`/`height` to 320) |
| Brand logo | (path in `BRAND_LOGO_SRC`) | `brand/fineverse-logo.jpg` | 1:1 | 160 x 160 | 512 x 512 |

`{view}` is one of: `front`, `back`, `detail` (a close-up of the print or fabric).

### Other values

- `categoryId`: `tees`, `oversized-tees`, `hoodies`, `accessories`
- `slug` (collections): `sisters-revenge`, `planet-x`, `essentials`, `orbit-zero`
- `dropId`: `drop-03`, `drop-04`, `drop-05`
- thumbnail `variant`: `drop-reveal`, `behind-the-print`, `unboxing`
- avatar `variant`: `orbit`, `comet`, `nebula`, `pulsar`

## Not in this folder

- **Social share image (Open Graph):** generated by `app/opengraph-image.tsx`. To use a photo,
  delete that file and add `app/opengraph-image.jpg` (1200 x 630).
- **Favicon / app icons:** `app/icon.svg`. To replace, add `app/icon.png` (512 x 512) and
  `app/apple-icon.png` (180 x 180), then delete `app/icon.svg`.
